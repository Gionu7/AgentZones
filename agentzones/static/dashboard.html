Lifecycle of a run

One round

Each round the aggregator sends the current global model to every client. Each client trains it on its own data, which never leaves its zone, and sends back new weights and its number of samples. The aggregator checks the updates and averages them, weighted by samples.

Agents in all zones

Agents register with their own zone's gateway every 10 s. Spoke gateways pass the list to the hub, which keeps one directory for all zones. Agents find each other by capability.

Proxy Doctor

Diagnoses proxy and certificate problems on its own machine. When unsure, it consults the doctors of the other zones, sending the diagnostic observation only. It shares a fix only after applying it and seeing the checks pass.

How spokes and the hub trust each other

Each spoke has its own token, shared only with the hub. The token is a signing key and never travels. A proxy on the path can read messages but cannot change them, replay them or use the token.
